==========================================
Flowplex Project Sample Design
==========================================

Below is a sample design with Flowplex Project, assuming that all necessary configuration and parameters are completed and all validations are passed. 

.. image:: images/flowplex_sampledesign.png
   :alt: Flowplex Sample Design
   :align: center
   :width: 80%

To view the connectivity, click any Initiator or Target Component. 

.. image:: images/flowplex_connectivity.png
   :alt: Flowplex Sample Connectivity Flow from MIM
   :align: center
   :width: 80%

.. image:: images/flowplex_connectivitySIM.png

   :align: center
   :width: 80%

.. note::
   If the connectivity for either direction is set to "Disconnected," no corresponding line connections will appear in the Design tab. Ensure that valid connectivity is configured for each component.


To view the connected interfaces to Linkports, click any connected "Linkport".
