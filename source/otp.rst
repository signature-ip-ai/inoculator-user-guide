============================================
Multi-Factor One-Time PIN (OTP) Verification
============================================

To protect system access and proprietary Network-on-Chip (NoC) design IP, the platform requires multi-factor authentication (MFA). After submitting your primary email and password credentials, you must validate your session with a unique, time-sensitive One-Time PIN (OTP).

--------------------------------------------------------------------------------

🔒 Step-by-Step Verification Sequence
======================================

Follow this operational flow to retrieve your verification key and access your engineering workspace:

.. grid:: 1
   :gutter: 3

   .. grid-item-card:: Step 1: Access the Token Input Interface
      :class-header: bg-light font-weight-bold

      **Authentication Intercept**
      
      Upon successful password validation, the system stalls portal access and displays the **OTP Verification** screen. The system holds your session in a pending state until a valid numerical key is submitted.
      
      .. image:: images/sign_in-otp_page3.png
         :alt: Multi-factor authentication input form for entering the One-Time PIN
         :align: center
         :width: 65%

   .. grid-item-card:: Step 2: Retrieve the Security Key
      :class-header: bg-light font-weight-bold

      **Inbox Monitoring**
      
      Check your registered corporate email inbox for an automated transaction message generated by the platform security layer. Copy the temporary numerical code embedded inside the notification body.
      
      .. image:: images/email_notification-otp_to_login.png
         :alt: Sample email notification from Signature IP containing the temporary security PIN
         :align: center
         :width: 80%

   .. grid-item-card:: Step 3: Initialize the Project Workspace Canvas
      :class-header: bg-light font-weight-bold

      **Session Grant**
      
      Return to the verification page, input the code string, and click submit. Once verified, the central authorization layer builds your session token and redirects you to the main **Project Hub Dashboard**.
      
      .. image:: images/successful_sign_in_screen2.png
         :alt: Successful login landing view displaying the active project management page
         :align: center
         :width: 85%

⏳ Technical Execution & Token Lifecycle Rules
==============================================

.. error::
   **Token Expiration Threshold:**
   Each dispatched security PIN is generated with a strict time-to-live (TTL) expiration window (typically 5 to 10 minutes). 
   
   If you do not submit the key before this expiration window drops, the token invalidates automatically. If your token expires or your network delays delivery, return to the login panel and click **Resend OTP** to generate a fresh verification block.

* **Spam Folder Isolation:** If the verification email does not arrive within 60 seconds, inspect your corporate mail appliance's spam or automated filter folders.
* **Session Persistence:** Completing the OTP handshake drops an authenticated cookie block into your active browser instance, preserving your workspace clearance level until explicit session termination or security timeout thresholds occur.
