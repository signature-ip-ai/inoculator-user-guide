=================================
Authentication and Portal Login
=================================

The platform enforces a secure, credentialed access pipeline. To load your cloud-hosted Network-on-Chip (NoC) design environments, simulation layers, and collaborative team forks, you must pass through the centralized identity validation gateway.

--------------------------------------------------------------------------------

Step-by-Step Portal Access Workflow
=======================================

Follow the sequence detailed below to complete your primary authentication handshake:

.. grid:: 1
   :gutter: 3

   .. grid-item-card:: Step 1: Access the Global Landing Hub
      :class-header: bg-light font-weight-bold

      **Domain Redirection**
      
      Point your verified workstation web browser to the primary server domain address: ``inoculator.ai/home``. Locate and click the primary **Log In** control button positioned on the main site header menu.
      
      .. image:: images/sign_in-home_page2.png
         :alt: Primary iNoCulator global landing page and login action entry point
         :align: center
         :width: 85%

   .. grid-item-card:: Step 2: Fulfill Identity Form Credentials
      :class-header: bg-light font-weight-bold

      **Credential Submission**
      
      Once the server redirects you to the secure sub-domain gateway, enter your fully registered corporate email address and unique password string into their respective input fields. Click the primary **Sign In** button to complete authentication.
      
      .. image:: images/log_in_page.png
         :alt: Secure portal login input forms and verification gateway overlay
         :align: center
         :width: 50%

--------------------------------------------------------------------------------

Pro-Tip for Seamless Access
==============================

.. hint::
   **Multi-Factor Security Handshake:**
   Depending on the security profile assigned to your organizational group tier, passing through the primary **Sign In** window may trigger a downstream request for a multi-factor authorization token. 
   
   Ensure you have your authentication token device or corporate inbox accessible to catch the validation string immediately after submitting this form. For subsequent security string verification steps, consult: :doc:`One-Time Pin (OTP) Validation <otp>`.
